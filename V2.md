# FC Helper 2.0.1

V2 открывается на вкладке «Моя коллекция»: команды, текущие тиры и следующие цели видны вместе. При первом запуске требуется синхронизация аккаунта; далее сохранённый результат отображается сразу, без выбора каждого набора.

## Исправление 2.0.1

Исправлена остановка общей синхронизации при повторе страницы клуба. В запрос передаются и смещение, и номер страницы. Повтор выдачи сохраняет найденные карты и помечает проверку клуба как частичную, не обрывая следующие наборы. Непроверенные карты не отмечаются отсутствующими; их покупка требует завершённой отдельной проверки клуба.

## Коллекция

- Поиск по названию, категории, фильтры завершённости и текущего тира.
- Для каждого набора: D/C/B/A/S, лучший собранный ранг, количество мест, очки и разница до следующего тира.
- Зелёные тиры подтверждены сохранёнными картами. Серый тир означает отсутствие подтверждения, а не обязательно отсутствие карт в аккаунте.
- Различаются неизвестные, частичные и свежие данные. Для набора с неполной проверкой показанный достигнутый ранг — нижняя оценка по известным картам.
- Кнопка «План до…» выбирает следующий несобранный тир. Можно выбрать отдельную букву ранга.
- Краткая инструкция и история последних покупок/пропусков доступны на этом же экране.

## Синхронизация

- Вся коллекция, категория или выбранный набор. Принудительная перепроверка доступна отдельно.
- Общие карты пересекающихся наборов проверяются один раз. Небольшие наборы обрабатываются первыми.
- Проверенные отрицательные статусы используются 30 минут. Положительная история Gallery сохраняется постоянно, в том числе после продажи.
- Если максимальный тир набора уже подтверждён историей, дальнейшие запросы только ради этого набора пропускаются. Это особенно важно для Starter Set с пулом более 21 тысячи карточек.
- Чтение идёт частями по 50 уникальных карт. Положительная история сохраняется до запроса клуба; время полной проверки части записывается только после успешной проверки клуба.
- Остановка и ошибки сохраняют завершённые части. Следующий запуск проверяет оставшиеся и устаревшие данные. Неопределённый ответ EA не превращается в подтверждённое отсутствие карты.
- История, имена, очки и время проверок сохраняются отдельно для persona EA. Данные версии 1.5.1 продолжают использоваться.
- Цены и характеристики больших пулов загружаются частями, без обрезания на первых 10 тысячах карт.

## Защита от переплаты

Сравнивается **точная версия карты на выбранной платформе**. Перед поиском лота обновляется ориентир FUT.GG с минутным кешем. Если свежая цена выше ещё актуального ориентира плана, сохраняется более низкий ориентир: рост цены не должен незаметно разрешать переплату.

| Ориентир | Лот EA | Автоматический режим |
|---|---|---|
| 1 000 | 1 000 | Покупка в пределах бюджета |
| 1 000 | 1 100 | Покупка: превышение ровно 10% |
| 1 000 | 1 150 | Только после ручного подтверждения |
| Неизвестен или старше 10 минут | Любая цена | Только после ручного подтверждения |
| Любой | Выше потолка или остатка бюджета | Покупка запрещена |

Диалог показывает найденную цену, ориентир, время его получения, процент разницы и жёсткий лимит. Отмена пропускает карту; Gallery пытается подобрать замену. Для полного плана автоматическая замена не может молча понизить целевой тир.

Поиск рынка теперь проверяет цены ниже лучшего результата первой выдачи: до четырёх последовательных запросов. Это ограниченный поиск лучшего найденного BIN, **не гарантия абсолютного минимума рынка**. FUT.GG может отставать от реальных торгов; время в интерфейсе — время получения ориентира помощником.

Защита действует для Gallery и ИПК. В полуавтоматическом режиме по-прежнему подтверждается каждая покупка. В автоматическом — каждая переплата свыше 10% и каждый лот без свежего ориентира.

## Надёжность сценариев

- Синхронизация, расчёт и покупка не запускаются одновременно из интерфейса. Изменение параметров сбрасывает устаревший план.
- «Стоп» проверяется после поиска и до отправки покупки. Уже отправленную операцию EA отменить нельзя.
- Проверка клуба читает страницы до завершения или обнаружения всех нужных карт. Повтор страницы и превышение лимита возвращают частичный результат. Общая синхронизация продолжает проверку Gallery, а перед покупкой непроверенное отсутствие карты блокирует покупку.
- Каждая подтверждённая покупка, включая покупку для ИПК, сохраняется в постоянной истории Gallery до перемещения предмета.
- Ошибка выдачи непринятых после успешной ставки не считается отказом покупки и не вызывает повторную ставку.
- После ошибки выставления `461` карта остаётся в трансфер-листе. Автоматической быстрой продажи больше нет.
- После запуска покупки план нужно пересчитать. Для ИПК перед расстановкой требуется повторная проверка клуба.
- Расчёт Gallery больше не открывает FUTBIN ради общей таблицы Item Score; импорт конкретного ИПК с FUTBIN сохранён.

## Установка обновления

Обновите файлы расширения, нажмите «Обновить» в `chrome://extensions`, затем перезагрузите вкладку EA. При сообщении о старом коде полностью закройте вкладку EA и откройте заново. Не удаляйте локальное хранилище: там находится история покупок.

Обновление базы через popup обновляет **каталог**, а не код расширения. Код V2 нужно загрузить из репозитория. Для первоначального заполнения обзора нажмите «Обновить всю коллекцию».

## Проверки

`npm test` запускает проверки синтаксиса, каталога, истории покупок, тиров, альтернатив, границы 10%, отсутствующих цен, остановки, очереди синхронизации, сохранения после ошибки, поиска более дешёвых лотов и страниц клуба.

`npm run test:ui` запускает установленный Chrome в изолированном профиле на полностью искусственных данных. Путь можно задать переменной `CHROME_PATH`. Проверяются стартовый обзор без запросов EA, фильтрация, переход к набору, расчёт плана, сброс после изменения бюджета и отсутствие горизонтального переполнения на ширине 390 px. Снимки экрана сохраняются в `tools/.artifacts/` и не публикуются в Git.

В реальном аккаунте EA покупки и продажи в рамках разработки не выполнялись. Совместимость с текущим внутренним API EA и точность внешних цен следует проверить небольшим планом в полуавтоматическом режиме. Поведение нескольких одновременно открытых вкладок EA не покрыто общей блокировкой операций: выполняйте покупки в одной вкладке.
