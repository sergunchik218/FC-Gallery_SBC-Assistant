# FC Gallery Assistant V3

V3 делает коллекцию и покупку понятными до нажатия любой рыночной кнопки.

## Что изменилось

- Каталог обновлён с 127 до **196 наборов**: добавлены актуальные команды MLS, NWSL, ROSHN Saudi League и новые наборы редкостей и лиг.
- Главный экран показывает заполнение каждого набора, Item Score, достигнутый тир, следующую цель и качество синхронизации.
- Настройка плана разделена на три понятных блока: цель, лимиты и поведение после покупки.
- В каждой строке плана видны точная версия карты, её очки, ориентир цены, пользовательский потолок и правило защиты от переплаты.
- Карты можно выбирать галочками: покупать весь план необязательно.
- Уже собранные карты вынесены отдельно и снабжены источником, поэтому видно, почему повторная покупка исключена.

## Как определяется собранная карта

Состояние объединяется только в сторону `собрано` и никогда автоматически не откатывается назад:

1. EA Gallery сообщает постоянный флаг точной версии карточки.
2. Точная версия найдена в текущем клубе.
3. Покупка была успешно подтверждена EA через помощник.
4. Ранее сохранённая история этого EA-профиля загружена из `chrome.storage.local`.

Перед каждой покупкой помощник повторно проверяет локальную историю, EA Gallery, клуб и непринятые предметы. Если EA не вернула однозначный статус, покупка останавливается или карта заменяется — неизвестное состояние не считается отсутствием.

## Обновление каталога

`tools/update-gallery-catalog.mjs` читает публичное описание наборов Gallery, извлекает только ожидаемые поля без исполнения кода страницы, объединяет их с собственной базой карточек и требует ровно 10 категорий / 196 наборов. Затем `tools/validate-gallery-catalog.mjs` проверяет все ID, пороги и динамические правила.

Расширение получает уже проверенный JSON из этого репозитория раз в неделю и всегда имеет встроенную резервную копию.

## Ограничения

- Состояние Gallery зависит от данных, которые текущая версия EA Web App отдаёт авторизованному пользователю.
- Новая промо-карта появится в локальном пуле после обновления `cards-27.json`; динамические правила клуба, лиги и редкости расширяются автоматически.
- Автоматизация рынка может нарушать правила EA. Полуавтоматический режим с подтверждением каждого лота остаётся рекомендуемым.
